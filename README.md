## **Installation**

1. Clonez le dépôt :
   ```bash
   git clone https://github.com/votre-utilisateur/votre-projet.git
   cd votre-projet

2. Assurez-vous d’avoir Node.js (version la plus récente)

3. Installez les dépendances :
   ```bash
   npm install

4. Lancez l’application :
   ```bash
   npx expo start -c
